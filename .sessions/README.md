# 📝 Sessions IA

Ce répertoire contient les journaux des sessions IA menées sur le projet **Super Chapelaine**.

## Convention de nommage

Chaque fichier est nommé selon le format :

```
AAAA-MM-JJ_HHhMM_modele.md
```

Par exemple : `2026-10-25_19h41_claude.md`

## Contenu d'une session

Chaque fichier de session contient :

- La **date et l'heure** de la session
- Le **modèle IA** utilisé
- La **branche git** active
- Les **objectifs** de la session
- Un **résumé** des travaux réalisés
- Les **décisions** prises

## Créer une nouvelle session

```bash
make session
```

Cette commande génère automatiquement un fichier de session pré-rempli avec les informations courantes.
